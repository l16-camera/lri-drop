LRI Drop is a small desktop converter for Light L16 .lri files. It inspects modules, pulls shots from the camera over adb, and writes per-module Adobe DNG — full set or mono only (A2 / C6) with optional PNG previews.

    Real conversion needs the Tauri build + luminat light crate. This page is the public face for the product.

    From capture to DNG

    Three short paths into the same queue.

    ↓

    Drop files

    Drag .lri onto the window. Each file is inspected for module count, focal length, and mono cameras before it sits ready in the queue.

    usb

    Pull from Light

    Connect L16 over USB. LRI Drop lists /sdcard/DCIM/Camera/*.lri via adb, pulls selected shots (with cache), then queues them like local drops.

    →

    Convert

    light::extract writes <output>/<stem>/*.dng. Optional mono-only pass keeps A2/C6; PNG previews land under mono/.

    Built for L16 workflows

    Fast shell around the same library as the fuller Luminat desktop app.

    Per-module DNG

    Every optical module becomes its own Adobe DNG for Lightroom, Capture One, or raw pipelines.

    Mono A2 / C6

    Export only mono channels as A2_mono.dng / C6_mono.dng with optional PNG previews.

    Camera queue

    adb status pill, remote list modal, multi-select pull, progress events while files move.

    Queue with progress

    Per-file cards: ready, pulling, running %, done with “open folder”, or error text.

    Native shell

    Tauri 2 on macOS — drag-drop from Finder, folder picker, reveal in Finder.

    Same light crate

    Parsing and extract come from luminat’s open light library — not a black-box converter.

    LRI Drop vs Luminat

    Same library, different product shells.

    Clone, link luminat, run.

    macOS, Rust, Node 20+, Xcode CLT. adb on PATH for camera features.

    git clone https://github.com/l16-camera/lri-drop.git
cd lri-drop
./scripts/link-luminat.sh
npm install
npm run tauri dev
