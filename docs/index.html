LRI Drop is a small desktop converter for Light L16 .lri files. It inspects modules, pulls shots from the camera over adb, and writes per-module Adobe DNG — full set or mono only (A2 / C6) with optional PNG previews. Brand chrome follows a circahue circadian accent (same living light idea as Luminat).

    Why so many raw files?

    One Light L16 shutter press is not one photo — it is a multi-camera capture packed into a single .lri. LRI Drop does not “multiply” frames; it unpacks what the hardware already recorded.

    MODULE ARRAY · which lenses fire at each focal length
    10 modules firing

    wide + mid
    2870150

    Measured on a live L16 (61 captures). Below ~70 mm the wide row (A) and mid row (B) expose; past it mid hands off to tele (C). Reference module = widest that fired. Each lit cell becomes its own DNG in LRI Drop.

    Separate frames from separate modules

    The L16 ships sixteen optical modules in three banks (A1–A5 · B1–B5 · C1–C6). A shutter press packs the active set into one .lri — not a stack of JPEGs, and not a fused “final” RAW. LRI Drop unpacks what the hardware already recorded.

    • ~10–11 DNGs per shot, not always 16 — only modules that fired write sensor data. Scrub the focal dial to see the handoff.
    • Not duplicates — each file is a different viewpoint / focal band / sensor. That is the multi-aperture raw for Lightroom or research.
    • Mono plates — A2 and C6 are monochrome (dashed cells). Mono-only export keeps A2_mono.dng / C6_mono.dng.

    From capture to DNG

    Three short paths into the same queue.

    ↓

    Drop files

    Drag .lri onto the window. Each file is inspected for module count, focal length, and mono cameras before it sits ready in the queue.

    usb

    Pull from Light

    Connect L16 over USB. LRI Drop lists /sdcard/DCIM/Camera/*.lri via adb, pulls selected shots (with cache), then queues them like local drops.

    →

    Convert

    light::extract writes <output>/<stem>/*.dng. Optional mono-only pass keeps A2/C6; PNG previews land under mono/.
